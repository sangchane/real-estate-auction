### Q1. 정비구역 폴리곤·단계 데이터를 어디서 가져올까요? (라이선스가 걸린 결정)
브이월드의 정비구역 데이터셋에는 "CC BY-NC-ND — 영리목적 이용 불가·변경 금지"가 명시되어 있어,
상용 서비스인 우리가 그대로 쓰면 라이선스 리스크가 있어요. 지시서의 브이월드 전제를 그대로 둘 수 없어요.

| 옵션 | 내용 | 근거·트레이드오프 |
|---|---|---|
| A (추천) | 폴리곤=토지이음(eum.go.kr) 정비구역정보 SHP(월간 파일) + 단계=서울 열린데이터광장 OA-2253(공공누리 1유형, 상업 이용 허용). 브이월드 미사용. 토지이음 이용조건이 페이지에 불명확하므로 착수 시 국토부에 서면 확인 1건 병행 | 상업 이용이 명시적으로 허용된 경로 중심. 파일 배치가 수집기 구조와도 맞음. 단점: 확인 회신 대기 가능성 |
| B | 지시서대로 브이월드 데이터 API 사용(키 발급 예정), 착수 전 API 약관·출처표시 의무 서면 확인 | 다운로드와 API 약관이 다를 가능성에 베팅. 확인 결과가 부정적이면 수집 경로 재작업 |
| C | 폴리곤 없이 1차 착수 — 단계 데이터(OA-2253)만으로 물건 상세에 "○○구역·조합설립인가(2024-03-11 고시)" 사실 표기, 폴리곤은 라이선스 확정 후 2차 | 법적 리스크 0으로 즉시 착수. 지도 시각화(이번 요청의 핵심)가 미뤄짐 |

### Q2. "주변 노후도"를 무엇으로 정의하고 어디까지 보여줄까요?
노후도는 법정 단일 기준이 없어요(준공 후 20~30년 범위에서 조례로 정함). 데이터 양과 구현 비용이
옵션에 따라 크게 달라져요.

| 옵션 | 내용 | 근거·트레이드오프 |
|---|---|---|
| A (추천) | 법정동 단위: 세움터 대용량(월간 표제부 전체 파일, 쿼터 없음)에서 서울만 적재 → 동별 "사용승인 20년/30년 이상 경과 건물 비율"을 물건 상세에 사실 표기 + 지도는 동 경계 음영 | 지오코딩 불필요(법정동코드만으로 집계), 부동산플래닛식 필지 단위 대비 구현비 1/10 수준. 단점: 동 단위라 "우리 골목" 해상도는 아님 |
| B | 반경/필지 단위: 건물 폴리곤+사용승인일(GIS건물통합정보)을 적재해 물건 반경(예: 200m) 실측 비율 계산 | 해상도 최상(부동산플래닛급). 단점: 서울 수십만 건물 폴리곤 적재·갱신 파이프라인 추가 — 이번 범위가 크게 불어남 |

## 신선도 3층 (07 SLO와 같은 값 — 초판의 "단계 7일" 폐기)

| 층 | 무엇을 재는가 | 값 |
|---|---|---|
| ① 배치 가드 | 이번 실행에서 **또 돌릴지** 판단 | 단계 **6일** / 폴리곤·법정동·노후도 **27일** (04 §3.4) |
| ② 실행 신선도 SLO | 마지막 SUCCESS 이후 경과일 | 단계 **≤10일** / 나머지 **≤40일** (07) |
| ③ 원천 갱신주기 | 원천이 값을 바꾸는 주기 | 단계 **분기**(데이터셋 메타) / 폴리곤 **"변경발생시"** / 노후도 월간(**미확인** A-V1) |

셋은 서로 다른 것을 잰다. ②를 지켜도 ③ 때문에 **표시되는 단계 값은 최대 1분기 뒤처질 수 있고**,
그 사실은 화면의 원천 기준일로 그대로 전달한다. 어느 층도 다른 층의 이름으로 부르지 않는다.
