# 11 — 착수 전 사용자 액션 (인증키·계정 발급)

작성 2026-08-20. 구역 레이어 기능은 **여기 적힌 발급이 끝나야 착수할 수 있다.**
코드로 대신할 수 없는 것만 모았다. 각 항목은 "무엇을 / 어디서 / 무엇이 풀리는가" 순이다.

각 원천의 실사 근거는 `01-recon.md`·`10-recon-additional-zones.md`, 선정 사유는 `decision-log.md`.

## 우선순위 1 — 이것부터

### A. 서울 열린데이터광장 인증키

- **어디서**: https://data.seoul.go.kr → 로그인 → 마이페이지 → 인증키 신청 (무료·즉시)
- **무엇이 풀리나**
  - **FR-003 (P0)** — `OA-22856 TbSeoulRedevStatus` 정비구역 **추진단계** 주간 동기화.
    단계가 없으면 FR-005의 단계별 표시가 통째로 성립하지 않는다.
  - 미확인 해소 — `BIZ_TYPE` 전량 덤프(가로주택이 이 API에도 있는지)와
    `DISTINCT BIZ_STAGE` 값 목록(매핑 사전 확정용).
- **비고**: 이 API 자체는 **공공누리 1유형**이라 라이선스 제약이 없다.
  실호출로 472행·`INFO-000` 응답까지 확인해 둔 상태다(GATE 3차).
- **넣을 곳**: `.env`의 `SEOUL_OPEN_DATA_API_KEY` (`.env.example`에 키 이름만 추가 예정)

### B. 브이월드 계정

- **어디서**: https://www.vworld.kr → 회원가입 → 로그인 (무료)
- **무엇이 풀리나**
  - **FR-001 (P0)** — 정비구역 폴리곤 `dsId=30335` SHP
  - **FR-017 (P1)** — 법정동 경계 `dsId=30603` SHP. 이게 있어야 물건→법정동 공간조인이 되고,
    그래야 **FR-010 노후도**가 물건 상세에 붙는다.
- **주의**: 익명 다운로드가 **0바이트**로 떨어지는 것을 실측했다. 로그인 후 **수동 1회 다운로드**가
  필요하고, 이후 갱신도 사람이 받아 드롭 폴더에 넣는 방식이다(DA-09).
  → 받은 zip을 어디에 둘지는 착수 시 정한다.

## 우선순위 2 — 착수 후에 해도 되는 것

### C. 서울시 문의 — 정보몽땅 데이터 라이선스

- **무엇을**: 정비사업 정보몽땅의 가로주택 목록·진행단계 엑셀에 **공공누리 유형 표시가 아예 없다.**
  표시가 없으면 이용 조건을 알 수 없어 그대로 쓸 수 없다.
- **무엇이 막히나**: **FR-019 (P2, 가로주택)** 의 단계 보강. 폴리곤은 OA-22712로 되므로
  가로주택 표시 자체가 막히는 것은 아니다.
- **어디에**: 서울시 주택정책실 (정보몽땅 운영 부서)

### D. 서울시 문의 — 별도 이용허락 (수익화할 때만)

- **지금은 필요 없다.** 비영리로 확정했다(DA-12).
- 수익화를 논의하게 되면 **NC와 ND를 함께** 요청해야 한다. 절차와 대안은
  `decision-log.md`의 **DA-12 상용 전환 체크리스트** 5단계에 적어 두었다.

## 발급이 끝나면 — 착수 첫 순서

발급 자체보다 **첫 실취득으로 미확인을 닫는 것**이 먼저다. 추측으로 설계하면 이 패키지가 두 번
겪은 실패를 반복한다(종료된 API로 페이징 설계 확정 / 출처 오귀속으로 원천 선정 뒤집기).

1. **OA-22712 zip 받아 코드정의표 열기** — 계정 없이 된다(익명 다운로드 실측 성공).
   동봉 `서울플랜+코드정의표(대민용).xlsx`가 `SCLAS_CL`(사업유형)·`PROPEL_CD`(추진단계) 정의를 준다.
   → 5개 구역 종류의 단계 사전이 여기서 확정된다.
2. **좌표계 확인** — OA-22712의 PRJ가 **Bessel 중부원점 계열**이라 기존 30335(EPSG:5186)와 다르다.
   pyproj로 확인하고 적재한다. **추측으로 5186을 넣으면 전국이 어긋난다.**
3. **A로 `BIZ_STAGE` 전량 덤프** → 단계 매핑 사전 확정. 사전에 없는 값은 "미확인" 버킷으로
   떨어뜨리고 리포트에 남긴다(모르는 값을 임의 버킷에 넣는 것이 곧 허위 사실이다).
4. **팔레트 실측** — `packages/design-tokens/src/colors.ts` 전량과, 같은 지도 화면에서 이미
   쓰이는 색(마커 7범주·하락률 배지 등)을 파일로 확인한다. 그 결과로 DA-14 ②의 색 배정표를 만든다.
5. **가로주택 분양권 매핑** — 코드정의표 + 소규모주택정비법 확인. 단계 이름 유추 금지(DA-14 ①).

## 아직 열려 있는 설계 결정

- **가로주택 분양권 매핑** (DA-14 ①) — 위 5번이 서면 FR-019를 P2에서 올릴지 재검토
- **신통 중복 표시 방지** (FR-020) — 구역지정에 도달하면 정비구역(FR-001)에 자연히 포함된다
- **구역 종류 색 배정** (DA-14 ②) — 위 4번 결과에 달렸다
